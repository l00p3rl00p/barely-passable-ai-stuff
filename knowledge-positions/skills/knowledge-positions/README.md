# Just-in-Time Knowledge skill

**Use [SKILL.md](SKILL.md).** It is the complete, self-contained JITK workflow.

It teaches an agent to **Reuse → Direct access → Explore → Discover**, using knowledge's Location, Relation and Proximity to find source-backed context at the moment it is needed, then evolve useful findings through authorized, evidence-backed contributions.

No separate Knowledge Positions skill, SDK read, OmniGraph installation, or helper script is required to use it. Use whichever source readers and knowledge tools are already available.
