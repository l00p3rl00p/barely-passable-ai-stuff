# Agent contribution and progressive disclosure (non-normative profile)

Read and verify relevant original evidence before relying on it. After meaningful work, preserve useful findings and qualified relationships without waiting for the human to request writeback. Do not manufacture a contribution. Touch model: admission by the KP writer is touch 0 (deterministic serialization). The first deterministic enrichment pass is touch 1. Agent or LLM contributions are touches 2 and 3, then the record grows outward. Do not use synthetic semantic inference or an embedding provider.

For knowledge contributions, consult [capture and contribution](../../research/omnigraph/skills/knowledge-positions-omnigraph/references/capture.md) only when the Knowledge Positions adapter is needed. For native database operations, delegate to the official `omnigraph` skill rather than maintaining competing instructions here. Native policies, access controls and collaboration remain authoritative.
