---
name: knowledge-positions-omnigraph
description: Capture, reuse, locate, relate and evolve knowledge in native OmniGraph without semantic inference.
---
Use the installed native OmniGraph skill for engine operations. This skill only adds the Knowledge Positions convention. See the local bundle RUNBOOK.md for adapter commands. Ask for the configured target and graph path if not already known; never invent a destination.

Knowledge = { Position. Relation. Proximity. Resonance. }. Position is source and within-source location; relation is qualified graph association; proximity is a declared deterministic lexical vector; resonance is use-dependent importance, not yet implemented.

On each task, pass four decision gates: (1) reuse sufficient context, (2) access a known identity/source directly, (3) inspect immediate relations, (4) discover only if insufficient. Stop at sufficiency. If a host supplies JIT context, use it first; no mandatory hook here. Read and hash-check evidence before relying on claims. Keep work in its appropriate domain; do not move or duplicate knowledge merely because another domain can discover it.

Capture actual reviewed source spans using adapter.py capture. When work produces a useful finding, retain it as an authorized source (prefer OKF Markdown where appropriate), capture it, and link qualified relationships. Use enrich when refining existing payload: admission is touch 1, two subsequent changes are allowed; after touch 3 grow outward. Do not invent relationships or touch every read. Before finishing meaningful work, contribute useful findings or state why no contribution is warranted. Native policies, branch lifecycle and permissions apply; do not create a branch unless needed, and complete legitimate temporary branches rather than accumulating abandoned work. Never use semantic embeddings or an embedding provider for this representation.

No new service, no MCP required. The adapter's CLI provides deterministic capture, read, search, link and enrichment. Native OmniGraph remains the shared workbench.
