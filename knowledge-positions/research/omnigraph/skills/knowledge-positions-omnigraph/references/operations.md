# Native operations

Use the version-matched native OmniGraph skill for the operation at hand, not its entire reference tree. Native permissions, credentials, branches and persistence are authoritative. Create branches only where isolation or policy requires them; merge or discard completed work according to policy. Never use overwrite casually. On uncertain writes, inspect graph state and exact commit before retrying. A conditional enrichment refusal means re-read and reconsider. For installation or repair consult the bundle RUNBOOK.md.
