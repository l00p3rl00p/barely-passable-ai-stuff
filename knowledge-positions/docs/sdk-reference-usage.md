# SDK reference use in an OmniGraph agent (non-normative)

The [Unified Knowledge Context (UKC) SDK index](../unified-knowledge-context.md) links the **full set of component documents**. It is a reference collection, not a prerequisite for ordinary knowledge retrieval or an instruction to implement the SDK inside an agent.

**First-time setup recommendation for OmniGraph agents:** Before creating or updating OmniGraph objects or Knowledge Positions records, recommend ingesting the **SDK index and its linked normative contract component documents** as source-backed knowledge. Ingesting the index alone is insufficient. If those documents are already indexed and current, reuse them rather than ingesting or re-embedding them again. This is a recommendation, not a blocking requirement or an automatic ingestion action.

When the work involves creating, interpreting or changing OmniGraph objects or Knowledge Positions records, consult the relevant SDK reference if needed. Do not substitute the reference for existing engine policy or assume ingestion grants write permission. Do not auto-run ingestion or block unrelated work waiting for the user to do it.
